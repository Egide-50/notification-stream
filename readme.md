NotifyStream – Notification Management Dashboard

NotifyStream is a modern notification management dashboard built with HTML, Tailwind CSS, and Vanilla JavaScript.
It allows users to manage notification channels, templates, logs, and subscribers in a clean and interactive interface.

🚀 Features
📊 Overview

Live notification stream table

Delivery success rate analytics

Sparkline charts

Quick send notification panel

📡 Channels

Configure Email (SMTP / SendGrid)

Configure SMS (Twilio)

Configure Slack (Webhook)

Placeholder for Push (Firebase)

Enable / Disable channels

Test connection buttons

📜 Logs

Search logs

Filter by:

Status (Sent, Pending, Failed, Server Error)

Channel (Email, SMS, Slack, Push)

Time range

Export CSV button

Pagination UI

🧩 Templates

Create new templates

Edit, duplicate, delete templates

Dynamic variables using {{variable}}

Support for:

Email

SMS

Slack

Push

👥 Subscribers

View subscribers list

Search subscribers

Filter:

Subscribed

Unsubscribed

Import CSV (UI only)

Add subscriber button (UI only)
